# Stand-off annotation

Stand-off annotation keeps an annotation apart from the text it concerns and connects the
two through a reference to the target, so that the text stays unchanged and several
annotations can address the same passage. TEI P5 4.12.0 describes its `annotation` element
as following the Web Annotation Data Model.
