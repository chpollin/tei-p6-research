# Reanchoring after edit

Reanchoring after edit is the situation in which the text under an annotation changes, so
that the annotation's target has to be located again on the new version and the fitness of
its interpretation has to be judged anew. This definition is a posit of the P6 proposal and
carries no source anchor.
