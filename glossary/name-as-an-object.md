# Name as an object

A name as an object is a name regarded in its own right, irrespective of the persons, places or
organizations it is attached to, with its components, variant forms and canonical form as the
matter of interest. In TEI P5 4.12.0 the term nym denotes the canonical or normalized form of a
name regarded in this way.
