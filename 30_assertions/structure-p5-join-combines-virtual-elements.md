# In TEI P5 4.12.0, the Non-hierarchical Structures chapter demonstrates join elements indicating the members of virtual sentences explicitly, and the join specification states that with scope root the indicated rooted subtrees become children of the virtual element created by join.

## Statement

In TEI P5 4.12.0, the Non-hierarchical Structures chapter demonstrates join elements that list target word identifiers to indicate the members of virtual sentences explicitly, and the join specification states that with scope root the indicated rooted subtrees become children of the virtual element created by join.

## Support

- [[20_distillates/documents/tei-p5-guidelines-nh-non-hierarchical-4.12.0#^s23]] — The chapter's example of join elements whose targets list the word identifiers of virtual sentences.
- [[20_distillates/documents/tei-p5-join-4.12.0#^s5]] — The specification's account of the scope value root. It covers no other scope value.
