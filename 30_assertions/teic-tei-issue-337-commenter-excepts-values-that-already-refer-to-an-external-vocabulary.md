# In TEIC/TEI issue 337, a commenter excepted those like a country element with key FR, which already refer to a particular external vocabulary, from their announced change of the key uses in the Guidelines' examples

## Statement

In TEIC/TEI issue 337, a commenter wrote that they would change all uses of key in examples in the Guidelines to the format ref="tag:example.org,2012:foo", except for those like a country element with key FR, which already refer to a particular external vocabulary.

## Support

- [[20_distillates/publications/teic-tei-issue-337#^s20]] — Comment 13 of 21, dated 2012-05-20. It carries the change of the key uses in the Guidelines' examples together with its exception as a participant's announced intent and establishes nothing about the Guidelines text of any release.
- [[20_distillates/publications/teic-tei-issue-337#^s21]] — The exception clause of the same comment.
