# In TEI P5 4.12.0, the description of att.personal states that the class provides common attributes for those elements which form part of a name, usually but not necessarily a personal name

## Statement

In TEI P5 4.12.0, the description of the attribute class att.personal states that the class provides common attributes for those elements which form part of a name, usually, but not necessarily, a personal name.

## Support

- [[20_distillates/documents/tei-p5-att.personal-4.12.0#^s1]] — The class description at the pinned release. It identifies the carrying elements by their function alone, names no member element, and names neither a membership of att.personal in another class nor any attribute of att.naming or att.canonical, so the route from a name-part element to key, ref, nymRef and role stays outside the English text of this class.
