# In TEI P5 4.12.0, the Guidelines state that interchange is improved by the use of tag URIs in ref instead of key, and point to another section of the Guidelines for the explanation

## Statement

In TEI P5 4.12.0, the Guidelines state that interchange is improved by the use of tag URIs in ref instead of key, and point to another section of the Guidelines for the explanation.

## Support

- [[20_distillates/documents/tei-p5-guidelines-nd-4.12.0#^s5]] — The chapter's statement on interchange. It attributes the improvement to the use of tag URIs in ref instead of key, not to ref as such, and it states no rule for an element that carries both attributes.
