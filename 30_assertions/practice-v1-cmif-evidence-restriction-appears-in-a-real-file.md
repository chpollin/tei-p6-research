# The sampled CMIF ODD replaces att.editLike with a class allowing only conjecture on optional @evidence, and a sampled file uses that value on a received date

## Statement

The sampled CMIF ODD replaces `att.editLike` with a class whose optional `@evidence` allows only `conjecture`. The sampled CMIF file `freieisen-stoeber.xml` carries `evidence="conjecture"` on the `date` of its `received` action. The pairing shows one attested use of the restricted value. It does not establish that the file is valid, that the value is common, or that the restriction suits correspondence editions.
