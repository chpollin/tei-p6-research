# In TEI P5 4.12.0, the key attribute of att.canonical provides an externally defined means of identifying the entity or entities being named, using a coded value of some kind

## Statement

In TEI P5 4.12.0, the key attribute of the class att.canonical provides an externally defined means of identifying the entity or entities being named, using a coded value of some kind.

## Support

- [[20_distillates/documents/tei-p5-att.canonical-4.12.0#^s2]] — The attribute description. It calls the means of identification externally defined without saying what it is external to, and it does not state the form of the coded value.
