# In TEI P5 4.12.0, nym contains the definition for a canonical name or name component of any kind

## Statement

In TEI P5 4.12.0, the element nym contains the definition for a canonical name or name component of any kind.

## Support

- [[20_distillates/documents/tei-p5-nym-4.12.0#^s1]] — The English definition of the element. It establishes what a nym holds and states nothing about its content model, its class memberships or the list element that holds it.
