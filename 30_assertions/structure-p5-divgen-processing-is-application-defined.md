# In TEI P5 4.12.0, the Default Text Structure chapter states that the application program or stylesheet in use determines the processing when a divGen element is rendered, while the TEI markup only identifies the location of the virtual division and provides some information about its kind.

## Statement

In TEI P5 4.12.0, the Default Text Structure chapter states that the processing to be carried out when a divGen element is rendered will be determined by the application program or stylesheet in use, and that the function of the TEI markup is simply to identify the location at which the virtual division is to be generated and to provide some information about the kind of division to be generated.

- [[20_distillates/documents/tei-p5-guidelines-ds-defaulttextstructure-4.12.0#^s39]] — The chapter's statement on the rendering of divGen and on the function of its markup.
