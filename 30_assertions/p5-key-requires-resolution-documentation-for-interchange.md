# In TEI P5 4.12.0, the use of key in interchange requires that documentation about how the key is to be resolved be sent to the recipient

## Statement

In TEI P5 4.12.0, the remarks on att.canonical state that key is more flexible and general-purpose, and that its use in interchange requires that documentation about how the key is to be resolved be sent to the recipient of the TEI document.

## Support

- [[20_distillates/documents/tei-p5-att.canonical-4.12.0#^s8]] — The class remarks on key. They establish the documentation obligation and state nothing about the form the documentation takes.
