# In TEI P5 4.12.0, the description of att.global.responsibility states that the class provides attributes indicating the agent responsible for some aspect of the text, the markup or something asserted by the markup

## Statement

In TEI P5 4.12.0, the description of the attribute class att.global.responsibility states that the class provides attributes indicating the agent responsible for some aspect of the text, the markup or something asserted by the markup.

## Support

- [[20_distillates/documents/tei-p5-att.global.responsibility-4.12.0#^s1]] — The class description at the pinned release. It establishes that the agent the class names may stand behind something asserted by the markup, and it names no element that carries the attributes, so whether an identification on a naming element counts as such an assertion and reaches an agent through this class stays outside the English text of the class.
