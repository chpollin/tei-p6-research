# In TEI P5 4.12.0, the Guidelines conclude that each statement about the changes of state in a person's life needs to be documentable, put into a time frame and relatable to other statements, because any such statement rests on some source, possibly several and possibly contradictory

## Statement

In TEI P5 4.12.0, the Guidelines describe changes in state as life-changing or identity-changing events such as birth, marriage or appointment to office, normally associated with a specific date or a fairly narrow date range, and conclude that because any statement about these aspects of a person's life rests on some source, possibly several and possibly contradictory, each such statement needs to be documentable, put into a time frame and relatable to other statements.

## Support

- [[20_distillates/documents/tei-p5-guidelines-nd-4.12.0#^s24]] — The conclusion the chapter draws from the source-dependence of statements about changes of state. It establishes the three properties such a statement needs, it binds them to statements about these events, and it states nothing about the elements and attributes that provide them.
