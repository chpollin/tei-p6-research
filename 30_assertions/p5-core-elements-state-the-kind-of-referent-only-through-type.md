# In TEI P5 4.12.0, the Guidelines note that the core elements let an encoder mark a text segment as a proper noun or referring string and specify the kind of object named or referred to only through the type attribute

## Statement

In TEI P5 4.12.0, the Guidelines note that the elements of the core module let an encoder mark a text segment as a proper noun or a referring string and specify the kind of object named or referred to only through a value of the type attribute, whereas the elements of the module of this chapter supply a detailed sub-structure for such referring strings and distinguish explicitly between names of persons, places and organizations.

## Support

- [[20_distillates/documents/tei-p5-guidelines-nd-4.12.0#^s1]] — The chapter's opening contrast between the core elements and the module. It establishes the purpose the Guidelines state for the module and establishes nothing about how the core elements are used in encoded material.
