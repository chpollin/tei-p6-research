# In TEI P5 4.12.0, the Guidelines state that the module provides elements to represent information about the person, place or organization to which a given name is understood to refer and to represent the name itself independently of its application, so that it can represent a personal name, the person being named and the canonical name being used

## Statement

In TEI P5 4.12.0, the Guidelines state, in the chapter on names, dates, people and places, that the module also provides elements to represent information about the person, place or organization to which a given name is understood to refer and to represent the name itself independently of its application, so that where the core module can only represent that a piece of text is a name, this module can further represent a personal name, the person being named and the canonical name being used. The main intended applications are biographical, historical or geographical data systems such as gazetteers and biographical databases integrated with encoded texts.

## Support

- [[20_distillates/documents/tei-p5-guidelines-nd-4.12.0#^s2]] — The purpose statement of the chapter's module, which the statement names only as the module. It states the three things the module can further represent and gives no definition of the canonical name.
