# In TEI P5 4.12.0, the description of source in att.global.source states that it specifies the source from which some aspect of this element is drawn

## Statement

In TEI P5 4.12.0, the description of the source attribute in the attribute class att.global.source states that it specifies the source from which some aspect of this element is drawn.

## Support

- [[20_distillates/documents/tei-p5-att.global.source-4.12.0#^s2]] — The attribute description at the pinned release. It establishes that the attribute names the source of some aspect of the element bearing it without saying which aspect, and it names no element that carries the attribute, so whether an identification on a naming element can cite its source through this class stays outside the English text of the class.
