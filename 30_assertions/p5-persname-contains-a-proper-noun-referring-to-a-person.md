# In TEI P5 4.12.0, the English description of persName states that the element contains a proper noun or proper-noun phrase referring to a person

## Statement

In TEI P5 4.12.0, the English description of the element persName states that the element contains a proper noun or proper-noun phrase referring to a person.

## Support

- [[20_distillates/documents/tei-p5-persname-4.12.0#^s1]] — The English description in the element specification. It establishes what the description says the element contains and states nothing about the attributes that reach the element, about its content model or about the descriptions in other languages.
