# In TEI P5 4.12.0, the Guidelines present a generic state of type nationality, a nationality element with the same text and an empty nationality element carrying a key and the dating attribute as encodings of the same information

## Statement

In TEI P5 4.12.0, the Guidelines allow the generic state or trait element to be used in preference to the more specific elements, and present a state of type nationality with label and desc, a nationality element with the same text and dating attribute, and an empty nationality element carrying a key and the dating attribute as encodings of the same information.

## Support

- [[20_distillates/documents/tei-p5-guidelines-nd-4.12.0#^s33]] — The chapter's equivalence claim among the three encodings of one statement, in the last of which the key value together with the dating attribute stands in for the textual content. It establishes the Guidelines' position and states nothing about how a key on a description element is resolved.
