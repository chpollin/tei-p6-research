# In TEI P5 4.12.0, the English description of idno states that the element supplies any form of identifier used to identify some object in a standardized way

## Statement

In TEI P5 4.12.0, the English description of the element idno states that the element supplies any form of identifier used to identify some object in a standardized way.

## Support

- [[20_distillates/documents/tei-p5-idno-4.12.0#^s1]] — The element description at the pinned release, the specification's own statement of purpose. It establishes that the element carries a standardized identifier of some object and states nothing about where the element may stand in a record, about which kinds of object it identifies beyond the description's open examples, or about how a value is resolved.
