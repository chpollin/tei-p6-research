# In TEI P5 4.12.0, the Default Text Structure chapter states that floatingText should be used to represent an independent text which interrupts the text containing it at any point but after which the surrounding text resumes.

## Statement

In TEI P5 4.12.0, the Default Text Structure chapter states that floatingText should be used to represent an independent text which interrupts the text containing it at any point but after which the surrounding text resumes.
