# In TEI P5 4.12.0, anchor attaches an identifier to a point whether or not it corresponds to a textual element

## Statement

In TEI P5 4.12.0, the English description of anchor states that it attaches an identifier to a point within a text, whether or not it corresponds to a textual element.

## Support

- [[20_distillates/documents/tei-p5-anchor-4.12.0#^s1]] — The definition applies whether or not the point corresponds to a textual element. It does not by itself establish identity across text versions.
