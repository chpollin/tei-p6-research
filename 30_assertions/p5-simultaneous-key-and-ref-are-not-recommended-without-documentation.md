# In TEI P5 4.12.0, the English remarks on att.canonical state that the simultaneous use of both key and ref is not recommended unless documentation explaining the use is provided for interchange, probably in an ODD customization

## Statement

In TEI P5 4.12.0, the English remarks on the class att.canonical state that the simultaneous use of both key and ref is not recommended unless documentation explaining the use is provided for interchange, probably in an ODD customization.

## Support

- [[20_distillates/documents/tei-p5-att.canonical-4.12.0#^s11]] — The class remarks on the co-occurrence of the two attributes. They establish the recommendation and the place the Guidelines expect the documentation to live, for the attributes as this class defines them.
