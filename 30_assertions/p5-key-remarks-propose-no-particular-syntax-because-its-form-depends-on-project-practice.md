# In TEI P5 4.12.0, the English remarks on key propose no particular syntax for the values of the attribute, because its form will depend entirely on practice within a given project

## Statement

In TEI P5 4.12.0, the English remarks on the key attribute in att.canonical propose no particular syntax for the values of the attribute, because its form will depend entirely on practice within a given project.

## Support

- [[20_distillates/documents/tei-p5-att.canonical-4.12.0#^s4]] — The remarks on key at the pinned release. They describe a live attribute whose value form is left to the project, with no deprecation and no move towards a URI syntax, which is the released state that stands against the deprecation wish reported in [[30_assertions/teic-tei-issue-337-author-reports-a-wish-to-deprecate-key-held-back-by-its-wide-use]]. The remarks state nothing about which elements carry the attribute.
