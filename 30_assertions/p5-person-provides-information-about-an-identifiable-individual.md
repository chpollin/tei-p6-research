# In TEI P5 4.12.0, person provides information about an identifiable individual

## Statement

In TEI P5 4.12.0, the element person provides information about an identifiable individual, for example a participant in a language interaction or a person referred to in a historical source.

## Support

- [[20_distillates/documents/tei-p5-person-4.12.0#^s1]] — The English definition of the element. It establishes the record's subject and states nothing about the containers that hold a person, about its identifier or about the relation between the record and the occurrences of the person's name in a text.
