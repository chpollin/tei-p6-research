# In TEI P5 4.12.0, the description of att.datable states that the class provides attributes for normalization of elements that contain dates, times, or datable events

## Statement

In TEI P5 4.12.0, the description of the attribute class att.datable states that the class provides attributes for normalization of elements that contain dates, times, or datable events.
