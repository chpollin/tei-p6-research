# In TEI P5 4.12.0, the ref attribute of att.canonical provides an explicit means of locating a full definition or identity for the entity being named by means of one or more URIs

## Statement

In TEI P5 4.12.0, the ref attribute of the class att.canonical provides an explicit means of locating a full definition or identity for the entity being named by means of one or more URIs.

## Support

- [[20_distillates/documents/tei-p5-att.canonical-4.12.0#^s5]] — The attribute description in the class specification. It establishes the purpose of ref in this class and states nothing about the ref element, about the pointing attribute of other classes or about what kind of resource a URI may address.
