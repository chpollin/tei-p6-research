# In TEI P5 4.12.0, span from identifies the starting node of the annotated span or, without to, the node for the entire annotated span

## Statement

In TEI P5 4.12.0, span from identifies the starting node of the annotated span or, without to, the node for the entire annotated span.

## Support

- [[20_distillates/documents/tei-p5-span-4.12.0#^s2]] — The attribute description distinguishes the starting-node case from the case where no to attribute is present. It does not specify a half-open character interval.
