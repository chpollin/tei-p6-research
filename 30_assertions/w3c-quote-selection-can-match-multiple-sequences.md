# W3C quote selection can match multiple sequences

## Statement

If multiple matching text sequences remain after processing the prefix,
exact text and suffix, the W3C 2017 Web Annotation Data Model recommends
treating a Text Quote Selector as matching all those sequences.

## Support

- [[20_distillates/publications/w3c-web-annotation-20170223#^s1]] — the recommendation applies to matches remaining after prefix, exact text and suffix processing, within this selector and dated specification.
